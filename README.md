# DeskUnity

**DeskUnity — Remote Access & Meetings, All in One.**

DeskUnity combines HD video meetings, chat and screen sharing with secure remote desktop control, in one fast app for Windows.

## Download

👉 [Download DeskUnity for Windows](https://github.com/stealth-dev361/desk-unity-releases/releases/latest/download/DeskUnity.exe)

Run `DeskUnity.exe`. It installs and opens by itself, and updates itself when a new version is released.

## Features

- 🎥 HD video meetings with chat and screen sharing
- 🖱️ Remote desktop control with a Desk ID, approval required
- ⌨️ Every key and shortcut, including the Windows key
- 📋 A clipboard that follows you between computers
- 🔒 Peer-to-peer and encrypted
